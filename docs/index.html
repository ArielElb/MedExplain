MedExplain AI — תיעוד ומדריך מערכת מקיף

MedExplain AI היא מערכת קלינית מתקדמת, אינטראקטיבית וחינמית להסבר ופענוח בדיקות דם, המיועדת להעצים מטופלים, לפשט ערכים רפואיים סתומים, ולספק הכנה ממוקדת לפגישה עם רופא/ת המשפחה.

🧠

הקשר רפואי רחב (Synergy)

ניתוח שילובי מדדים המצביעים על תבניות משותפות (כגון אנמיה מחוסר ברזל, תסמונת מטבולית או דלקת) ולא רק בחינה מבודדת של ערך בודד.

📈

מעקב מגמות (Trends)

השוואת תוצאות נוכחיות לבדיקות עבר, חישוב שינוי באחוזים (Delta %) והצגת חצי מגמה גרפיים עם פרשנות קלינית ברורה.

🤖

עוזר AI חכם (MedBot)

צ'אט-בוט אינטראקטיבי המשלב מנוע קליני מקומי מהיר וחיבור רשות למודלי Google Gemini (2.0/1.5 Flash) עם שאלות מותאמות אישית.

📄

דף הכנה לרופא (Visit Brief)

טופס מובנה, ממוקד ומוכן להדפסה (A4) עם צ'ק-ליסט שאלות מתועדפות ומקום להערות הרופא/ה.

🛡️ מודל פרטיות 100% Client-Side

בניגוד לשירותי בריאות מקוונים רבים, MedExplain AI תוכננה מיומה הראשון עם אפס שרתים מרכזיים לעיבוד נתונים רפואיים:

🔒

פרטיות מוחלטת מובטחת בארכיטקטורה: כל חישובי הנורמה, השילובים, טווחי הגילאים והמגמות מבוצעים בדפדפן של המשתמש בלבד (Local Execution). אין שמירה של תוצאות רפואיות בבסיסי נתונים חיצוניים.

  • היסטוריית בדיקות: נשמרת ב-localStorage של הדפדפן בלבד, וניתנת להפעלה, השבתה ומחיקה מלאה בלחיצה אחת.
  • מפתחות Gemini API: נשמרים מקומית במכשיר המשתמש ונשלחים ישירות מקצה הדפדפן ל-Google, ללא שרתי ביניים (Proxy-Free).

🧩 שילובי מדדים (Cross-Test Matrix)

מנוע הסינרגיה מזהה דפוסים רב-מדדיים ומפיק תובנות על התמונה הכוללת:

אנמיה וחוסר ברזל

המוגלובין נמוך + פריטין נמוך + ברזל נמוך

מעיד על אנמיה כתוצאה מריקון מאגרי הברזל בגוף. המערכת מייצרת המלצות לשאלות על תוספי ברזל, מקור הדימום ובדיקות ספיגה.

דפוס מטבולי משולב

טריגליצרידים גבוהים + HDL נמוך + גלוקוז גבוה

דפוס אופייני לתנגודת לאינסולין ולתסמונת מטבולית. המערכת מדגישה כיווני תזונה דלת סוכרים פשוטים ופעילות אירובית.

תגובה דלקתית פעילה

WBC גבוה + CRP גבוה

שילוב המעיד על פעילות מוגברת של מערכת החיסון עקב תהליך זיהומי או דלקתי חריף/כרוני.

🤖 ארכיטקטורת Dual-Engine AI

העוזר הרפואי פועל במודל היברידי כפול המאפשר גמישות מקסימלית:

Dual-Engine Implementation (src/lib/ai/geminiService.ts) 
// Dynamic Google Gemini Model Discovery & REST fallback
export const validateGeminiApiKey = async (key: string) => {
  const cleanKey = sanitizeApiKey(key);
  // 1. Queries GET /v1beta/models to discover active models for this account
  const models = await fetchAvailableModelsForKey(cleanKey);
  
  // 2. Tests ping on the best candidate (gemini-2.0-flash / gemini-1.5-flash)
  const result = await callGeminiRest(cleanKey, models[0], "Ping test", ...);
  return { valid: true, activeModel: models[0] };
};

🚀 הרצה מקומית ופיתוח (Quickstart)

דרישות קדם: Node.js 18+ ו-npm.

Bash / Terminal 
# 1. שיבוט המאגר
git clone https://github.com/ArielElb/MedExplain.git
cd MedExplain/blood-test-app

# 2. התקנת תלויות
npm install

# 3. הרצת שרת פיתוח
npm run dev

# 4. בדיקת טיפוסים ובניית גרסת Production
npm run typecheck
npm run build

🐳 פריסה עם Docker ו-Render

הפרויקט כולל Dockerfile מבוסס Multi-stage build עם Nginx וקובץ render.yaml מוכן לפריסה אוטומטית.

Docker Commands 
# בניית ה-Container
docker build -t medexplain-app .

# הרצת ה-Container על פורט 80
docker run -d -p 80:80 --name medexplain medexplain-app
